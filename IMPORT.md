# Импорт отчётов раскроя

Импорт работает локально; исходные файлы не изменяются. Excel, Adobe Reader,
Python и отдельные библиотеки на компьютере заказчика не нужны.

## Порядок работы

1. Откройте **Заказ → Лазерная резка → Импорт файлов…** и выделите несколько
   файлов либо выберите каталог и нажмите **Импорт папки**. Вложенные каталоги
   автоматически не сканируются.
2. В **Раскроях и материалах** отметьте нужные программы. Двойной щелчок открывает
   материал из справочника, цену целого листа/трубы, рабочий центр, недостающее
   время и массу заготовки. Для материала из справочника проверяются толщина и
   формат листа; цена берётся из справочника. Можно оставить материал из файла
   и задать цену вручную. Это снимок материала в заказе, а не новая запись справочника.
3. Выберите основу расхода: **Полная заготовка** (по умолчанию) или
   **Минимальная заготовка** (доля площади листа / использованной длины трубы).
   Количество смен листов при этом не меняется. Для труб смены листов не начисляются.
4. В **Деталях и сопоставлении** проверьте наименования и количества. По умолчанию
   новая позиция создаётся в новом узле «Импорт раскроев». Можно выбрать существующий
   родительский узел. Количество из файлов считается общим: при вложении в узел
   с количеством 2 импорт 8 деталей создаст по 4 детали на один узел. Неделимые
   количества отклоняются, а заказ остаётся без изменений.
5. Двойной щелчок по детали позволяет выбрать существующую позицию, создать новую
   или оставить строку только в таблице сопоставления. Автосопоставление использует
   обозначение/имя и толщину; неоднозначные совпадения требуют ручного выбора.
   Разные детали нельзя одновременно сопоставить с одной позицией заказа.
6. Площадь в файлах — площадь плоского контура. Выберите одну или две стороны
   для покраски. По умолчанию — две стороны, без добавления площади кромок.
   Количество существующих вручную созданных деталей сохраняется, если не включён
   флаг его обновления. Для автоматически созданных импортом деталей количества
   разных раскроев суммируются, пока количество не изменено вручную.
7. Проверьте **Замечания и источники**, затем нажмите **Добавить выбранное в заказ**.
   До подтверждения заказ не меняется. После импорта черновик сохранён; для истории
   нажмите **Записать заказ**. В отчёте сохраняются источники и замечания.

## Поддерживаемые образцы и единицы

| Формат | Что читается | Чего нет в файлах |
| --- | --- | --- |
| BIT XLSX/PDF | Программа, материал, толщина, формат и минимальная заготовка, листы, использование площади, общее время, имена, размеры, площади, массы, количество деталей | Станок, время каждой детали, масса целого листа, цены |
| TruTops HTML | Программа, станок, материал, толщина, заготовки, прогоны, отходы, масса листа, машинное время, имена GEO, размеры, площадь, масса и время каждой детали | Цены |
| Sekirus PDF | Сечение трубы, длина, фактически использованные трубы, остаток, мёртвая зона, детали, количества, длины и длины реза | Марка металла, толщина стенки, масса, площадь поверхности, время резки, цены |

Миллиметры сохраняются как миллиметры, мм² переводятся в м², время Ч:М:С — в минуты.
Округление при отображении не меняет точность сохранённых значений.

В BIT `Part Quantity` в этих образцах содержит **кг**, а количество деталей —
`Nested Count`. Поле `Quantity` в сводке не считается массой целого листа.
`Estimated Time` берётся как общее время программы; `Piercing Time` сохраняется
справочно и второй раз не прибавляется. Отдельное время деталей не распределяется
по догадке. Неизвестные величины отображаются как «—».

В Sekirus `4 / 4` — размещённое/требуемое количество деталей. Проверяется совпадение
с повторным списком вложения, но этот список не прибавляется второй раз.
`1 / 999` означает одну используемую трубу при доступных 999; `R3` — радиус,
а не толщина стенки. В образце используются одна труба 6000 мм, четыре стойки
799 мм и четыре поперечины 304 мм. Остаток — 1728,04 мм.

## Обнаруженные расхождения

В исходных BIT-файлах сумма масс деталей не совпадает с итогом отчёта:

| Файл | Сумма масс деталей × количество, кг | Итог `Quantity`, кг |
| --- | ---: | ---: |
| 08ps0_8 | 141,5445 | 11,3235 |
| 08ps1_2 | 1,9178 | 0,2301 |
| 08ps2 | 7,2996 | 1,4598 |
| 08ps3 | 1,0732 | 0,3220 |

Поэтому противоречивые массы **по умолчанию не переносятся** в детали. Их можно
явно разрешить флагом в окне импорта. Все исходные значения сохранены в журнале
для сверки; плотность материала и «исправленные» массы не подставляются.
Для отсутствующих масс, времени и цен приложение показывает замечания о неполном
расчёте. Заполните их вручную перед использованием итогов.

## Повторный импорт и обновление

- Одинаковые раскрои PDF и XLSX определяются по программе и содержимому,
  а не только по имени файла. При выборе обоих остаётся одна копия (Excel).
- Уже загруженные программы по умолчанию не выбираются и не добавляются повторно.
- Для исправленного файла отметьте его и включите **Заменить выбранные ранее
  загруженные раскрои**. Старые импортированные строки этого раскроя заменяются;
  ручные строки и другие программы сохраняются.
- Если замена оставляет старую автоматически созданную деталь без источника,
  импорт останавливается с пояснением: сначала удалите ненужную деталь или измените
  сопоставление. Вручную изменённые данные не удаляются автоматически.
- Разные варианты одной программы с противоречивыми данными в одном наборе
  отклоняются. Загрузите нужный вариант отдельно.
- **Только площадь и массу** обновляет только известные значения сопоставленных
  деталей, не создаёт раскрои, не меняет время или количества. Неизвестные поля
  никогда не затирают уже заполненные значения.

Образцы `1c_файлы_мишы` дают **9 уникальных раскроев, 41 уникальную позицию,
152 детали**. Четыре пары PDF/XLSX исключаются как повторы. Известное машинное
время — **18,25 мин**, без неизвестного времени трубной резки и надбавок этапа.

Поддерживаются именно эти семейства отчётов, а не произвольные таблицы Excel
или PDF. Сканированные PDF без текстового слоя не распознаются. Вариант BIT
с Count/sheet Count, отличным от 1, требует отдельного образца для проверки
того, указаны ли количества и времена на лист или на весь заказ; такой файл
не импортируется молча с предположением о множителе.
